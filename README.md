# 🐋 DSH 语音助手

> 一句话唤醒的 Windows 语音助手：**说"老梁"就能让它帮你干活**。

对着麦克风说一声 **"老梁"**（或 **"梁文峰"**、**"梁总"**），然后说出你想做的事——
它听懂后会**语音回复你，并真的去执行**。像手机上的 Siri，但活在 Windows 桌面上，
而且更听你的话。

## 🎬 它能做什么

| 你说 | 它做 |
|------|------|
| "老梁，打开记事本" | 打开记事本 |
| "老梁，搜索深圳天气" | 浏览器搜天气 |
| "老梁，下一首" | 播放器切歌 |
| "老梁，5分钟后提醒我喝水" | 到点主动语音提醒你 |
| "老梁，截个图" | 全屏截图保存到图片目录 |
| "老梁，推送到GitHub" | 在项目目录执行 git 提交推送，并播报结果 |
| "老梁，打开战神5" | 从开始菜单/Steam/Epic 找到并启动游戏 |
| "老梁，你叫什么名字" | 回答"我叫梁文峰" |
| "没事了 / 退下" | 结束对话，安静待命 |

> 不止这些——它由大模型驱动，**几乎所有能用嘴说的指令都能理解**，
> 而且拥有全局权限：文件、命令、脚本、系统操作都可以语音执行。

## 🚀 快速开始（2 分钟，不用懂技术）

**第 1 步：安装**
从 [GitHub Releases](https://github.com/Winston-Rowan/DSHVoiceAssistant/releases) 下载
`DSHVoiceAssistant-Setup-1.0.0.exe` 并运行，一路点"下一步"。
（Windows 提示"发布者未知"时点 **更多信息 → 仍要运行**——未签名安装包的正常提示，
代码签名证书太贵了，作者以后会买的 😄）

**第 2 步：配置密钥**
首次启动会弹出**欢迎引导窗口**，跟着做就行：
1. 点「打开百炼控制台」→ 免费注册/登录阿里云 → 右上角 **API-KEY** → 创建并复制密钥
2. 点「打开设置填写密钥」→ 粘贴 → 保存
3. （可选）想用 DeepSeek 官方 API 做指令引擎：设置 → API 配置 → **DSH API** 区填 DSH 密钥
   （留空则自动用百炼密钥，不用管也行）

**第 3 步：开聊**
对着麦克风说 **"老梁"**（或按 **Win+F2**）→ 说出指令，例如：
"老梁，打开记事本"、"老梁，搜索深圳天气"、"老梁，5分钟后提醒我喝水"。
说 **"没事了 / 退下"** 或按 **ESC** 结束对话。

## ✨ 亮点

- 🎙️ **唤醒免费又省心**：本地离线唤醒，不花一分钱 API 额度；唤醒词可自定义
- 🧠 **真·大模型理解**：指令理解由大模型完成，不是死板的命令表
- 💬 **连续对话**：唤醒一次说多件事，不用反复呼叫；说"退下"或按 **ESC** 随时结束
- 🎨 **Siri 风格光效**：被唤起时（窗口开关都显示）屏幕边缘亮起彩色流光（倾听绿/思考紫/执行红/播报蓝）
- 🗨️ **对话浮层**：窗口隐藏时，对话文字透明显示在屏幕中下部，不打扰工作
- 🔊 **沉稳男声**：Andre 磁性男声回复（可换音色），断网自动切本地语音
- 🛡️ **权限可控**：完全访问 / 工作区受限 / 只读 三档，防误操作
- 🐋 **黑鲸鱼图标**：与 DSH 同款，托盘常驻、开机自启可选

## ❓ 常见问题

**Q：需要哪些 API 密钥？**
两个，各管各的：**百炼密钥**（语音识别/TTS，在语音助手设置里填）+ **DSH 密钥**
（DSH 环境的 Agent 会话，在 DSH Desktop 里配置，DeepSeek 官方 API key）。

**Q：唤醒没反应？**
麦克风权限/设备没选对时先看设置 → 麦克风与检测；确认唤醒词是"老梁"（可改）。
低增益麦克风也不用担心，应用会自动适配增益和底噪。

**Q：下载被 Windows 拦截？**
未签名的个人安装包都会这样。点"更多信息 → 仍要运行"，或右键安装包 → 属性 → 勾选"解除锁定"。

**Q：回答被自己的声音打断？**
默认开启了"自声过滤"，不会自己打断自己；想恢复语音插嘴，可在设置 → 界面与反馈 里关闭。

**Q：想换音色 / 唤醒词 / 快捷键？**
都在设置里：唤醒与对话（唤醒词/快捷键）、语音播报（音色）、界面与反馈（光效/浮层样式）。
