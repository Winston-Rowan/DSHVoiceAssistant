# 📋 需求与演进记录（DSH 语音助手）

> 本文档汇总本项目的全部用户需求与实现状态，供协作与评审使用。
> 项目：DSHVoiceAssistant（C# / WPF / .NET 8 Windows 桌面语音助手）
> 作者：Winston-Rowan & DSH

## 一、产品定位

一个 Windows 桌面语音助手（类似 Siri 的使用体验）：说唤醒词（"老梁/梁文峰/梁总"）唤醒，
下达指令（打开应用/搜索/系统操作/文件/媒体/命令/提醒等），助手**语音回复并真实执行**。
指令理解与决策全部由大模型（DSH 执行引擎）完成，本地只做语音采集、唤醒检测、展示与动作落地。

## 三、技术架构

```
用户语音 → DSH应用(NAudio麦克风采集, 数字增益+底噪自适应)
        ├─ 本地唤醒(SAPI词表, 原始音频) → 命中唤醒词（免费/离线）
        ├─ 前置缓冲(0.6s) 回填 → VAD 判定 → 录音
        └─ 指令录音 → 云端语音识别(omni) → 文本指令
        → DSH引擎(chat/completions + 系统提示词[身份/权限/12类动作]) → 结构化JSON
        → 本地执行器(应用/搜索/系统/文件/脚本/媒体/网址/提醒/截图/剪贴板) → 动作落地
        → TTS语音反馈(Andre男声) + Siri光效 + 对话浮层 + 界面展示
```

## 四、关键设计决策

| 决策点 | 结论 |
|--------|------|
| 自声过滤 vs 插嘴打断 | 开关默认开启过滤；关闭恢复插嘴（无 AEC 无法兼得） |
| 本地唤醒输入 | 原始音频（SAPI 自带 AGC，对增益音频识别差——日志实证） |
| 权限模型 | 提示词软约束 + 执行器硬拦截双层 |
| 结束对话 | 语音词条 / ESC / 静默超时三种方式 |
| 光效渲染 | 纯 WPF 动画（无 ShaderEffect），透明度分层近似高斯模糊 |

## 五、环境与配置

- Windows 10/11 x64、.NET 8 SDK、阿里云百炼 API（语音识别/语音合成）
- 密钥分工：**百炼密钥**（语音助手设置内配置，ASR/TTS/指令模型）；**DeepSeek 官方 API key**
  （`DEEPSEEK_API_KEY`，DSH 环境自身 Agent 会话用，在 DSH Desktop 内配置）
- 配置：`Config/appsettings.json`（自动生成，密钥不入库，可用环境变量 DSH_API_KEY）
