# 🎬 演示脚本（DSH 语音助手）

> 面向观众/朋友/评审的完整演示流程，约 10 分钟。
> 编排逻辑：认知 → 能力 → 深度 → 视觉高潮 → 安全收尾 → 闹钟闭环谢幕。

## 演示前准备

1. 安静环境，麦克风离嘴 30~50cm；先私下测一次唤醒（底噪自适应首次校准）
2. 设置确认：`EdgeGlowEnabled` 开启、权限模式=完全访问
3. Git 仓库留一个未提交改动（可选：现场演示"推送到GitHub"）
4. 备用方案：Win+F2 快捷键唤起；网络不稳时提前说明"云端推理"

## 演示流程

### ① 开场 · 认知（1 分钟）
- 你说：**"老梁，你是谁？"**
- 预期：唤醒 → 屏幕边缘光效亮起（青蓝）→ 回复（梁文峰人格）
  "我叫梁文峰，DeepSeek 创始人，现在兼职当你的桌面助手。"
- 看点：唤醒体验 + 人格化身份

### ② 基础执行（1 分钟）
- 你说：**"老梁，打开记事本"**
- 预期：一句简短确认，记事本真的打开
- 看点：说话就能干活，简单操作不啰嗦

### ③ 后台任务（30 秒，埋彩蛋）
- 你说：**"老梁，5分钟后提醒我喝水"**
- 预期：回复"好的，5分钟后提醒您。"——闹钟后台挂起
- 看点：后台定时能力（结尾自然响起，首尾呼应）

### ④ 复杂操作（2 分钟）
- 你说：**"老梁，看看D盘还剩多少空间"**
- 预期：执行（光效橙色）——全程不播报中间过程，执行完才播报
  "D盘剩余空间：30.5 GB"（真实脚本输出，强制中文，无外语腔）
- 看点：custom_script 通用执行 + 结束后汇报 + 中文保障

### ⑤ 视觉高潮（2 分钟）
- 操作：点关闭按钮隐藏窗口
- 你说：**"老梁，打开微信"**
- 预期：
  1. 屏幕四边流光特效亮起，随状态变色（倾听青蓝→思考紫→执行橙→播报粉）
  2. 桌面中下部透明浮层显示「我：打开微信 / 梁文峰：正在为您启动微信」
  3. 微信真的打开 + 语音播报
- 看点：Siri 光效 + 浮层 + 真实执行三连（全场最亮眼）

### ⑥ 安全收尾（2 分钟）
- 操作：设置 → API 配置 → 权限模式切到**只读** → 应用
- 你说：**"老梁，把D盘的文件删掉"**
- 预期：**"只读模式下禁止删除文件，请切换权限模式。"**（执行器硬拦截）
- 操作：权限切回**完全访问** → 应用
- 看点：权限三档模型，可靠可控

### ⑦ 闭环谢幕（1 分钟）
- 你说：**"退下"**（或按 ESC）
- 预期：语音结束对话，回到待命；此时若已满 5 分钟，
  **闹钟响起**："该喝水啦。"——首尾呼应的彩蛋闭环
- 看点：语音结束对话 + 后台提醒闭环

## 可替换/加演环节

| 环节 | 说明 |
|------|------|
| 推送到GitHub | "老梁，推送到GitHub" → git 提交推送 + 播报真实结果（演示前留未提交改动） |
| 剪贴板 | "把今天天气不错复制到剪贴板" → "看看剪贴板里有什么" |
| 截图 | "老梁，截个图" → 保存图片目录并播报路径 |
| 多轮对话 | 连续下达 2~3 条指令，展示连续对话无需重复唤醒 |
| 自定义人格 | 设置 → 助手人格 → 改成"毒舌吐槽型" → 看回复风格变化（DSH 自动优化） |
