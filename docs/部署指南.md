# 部署指南

## 一、前置要求

1. **.NET 8 SDK**（含 Windows Desktop）：<https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0>
   - 安装时勾选 ".NET Desktop Runtime"（默认包含）
   - 或在 Visual Studio 2022 安装器中勾选 ".NET 桌面开发" 工作负载
2. **Windows 10/11 x64**，可用麦克风
3. **两个 API 密钥（各管各的，都在设置 → API 配置 里配置）**：
   - **百炼工作台密钥**（阿里云百炼控制台 → API-KEY 管理）：语音助手的
     语音识别（`qwen3.5-omni-flash`）与语音合成（TTS）使用
   - **DeepSeek 官方 API key**（`DEEPSEEK_API_KEY`）：指令引擎（DSH API）使用，
     填写后指令引擎走 `api.deepseek.com`（默认地址，可改）；**留空回退使用百炼密钥**；
     环境变量 `DEEPSEEK_API_KEY` 可覆盖。DSH 运行环境自身的 Agent 会话同样使用
     该密钥（在 DSH Desktop 中配置）
4. **本地唤醒**：默认 `WakeMode=local` 使用 Windows 内置语音识别引擎
   （Windows 10/11 中文版自带 zh-CN 引擎，无需额外安装；英文系统需添加对应语言包）

## 二、编译

### 命令行

```bat
cd DSHVoiceAssistant
build.bat
```

脚本会依次执行：还原 → 编译（Release）→ 发布到 `publish\win-x64\`。

### Visual Studio 2022

1. 打开 `DSHVoiceAssistant.sln`
2. 右键解决方案 → 还原 NuGet 包
3. 生成 → 生成解决方案

## 三、发布

### 方式 1：框架依赖（推荐，体积小，目标机需装 .NET 8 Desktop Runtime）

```bat
dotnet publish src\DSHVoiceAssistant\DSHVoiceAssistant.csproj -c Release -o publish\win-x64
```

### 方式 2：自包含单文件（目标机无需安装运行时，体积约 150MB+）

```bat
dotnet publish src\DSHVoiceAssistant\DSHVoiceAssistant.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish\win-x64-standalone
```

## 四、安装与配置

1. 将发布目录复制到目标机器，如 `C:\Program Files\DSHVoiceAssistant\`
2. 首次运行前编辑 `Config\appsettings.json`：
   - `ApiKey`：填入你的百炼密钥（**推荐改为环境变量 `DSH_API_KEY` 注入**）
   - `SpeechModel` / `DSHModel`：确认工作台可用模型名
3. 运行 `DSHVoiceAssistant.exe`
4. （可选）在设置窗口勾选"开机自动启动"（写入 HKCU 注册表 Run 键）

## 五、开机自启动

- **设置窗口勾选**：设置 → 行为选项 → 开机自动启动（推荐，写入注册表）
- 手动注册：

```bat
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v DSHVoiceAssistant /t REG_SZ /d "\"C:\Program Files\DSHVoiceAssistant\DSHVoiceAssistant.exe\"" /f
```

- 取消：

```bat
reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v DSHVoiceAssistant /f
```

## 六、测试场景自检

| 场景 | 操作 | 预期 |
|------|------|------|
| 唤醒 | 说 "老梁"（或"梁文峰""梁总"） | 状态变"倾听中" |
| 结束对话 | 说"退下" 或按 ESC | 立即回到待命 |
| 打开应用 | "打开计算器" | 计算器启动 + 语音回复 |
| 搜索 | "搜索深圳天气" | 浏览器打开百度搜索 |
| 闲聊 | "你好吗" | TTS 朗读回复 |
| 媒体 | "下一首" | 当前播放器切歌 |
| 断网 | 关闭网络后说话 | 语音提示网络错误，程序不崩溃 |
| 长时间运行 | 挂机 24 小时 | 内存稳定（日志在 logs/ 目录可查） |

## 七、卸载

1. 托盘右键 → 退出
2. 删除安装目录
3. 删除注册表 Run 项（见第五节"取消"）
4. 日志目录 `logs/` 一并删除即可
