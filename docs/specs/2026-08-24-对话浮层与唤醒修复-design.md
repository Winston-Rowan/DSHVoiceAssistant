# 设计文档：对话浮层（透明显示）+ 本地唤醒回归原始音频

日期：2026-08-24
状态：已实现，待验证
适用范围：DSHVoiceAssistant（WPF / .NET 8）

## 需求

1. **对话浮层**：主窗口关闭（静默运行）时，有对话时在桌面中下部展示对话内容——
   **无背景（全透明）、文字不透明**。
2. **唤醒修复**（诊断定位）：日志显示本地 SAPI 唤醒引擎对**增益后**音频
   （RMS 0.044）返回空结果（`唤醒引擎无识别结果`），门控/底噪均正常；
   而此前版本唤醒正常时喂给 SAPI 的是**原始音频**。

## 方案

### 对话浮层（ConversationOverlayWindow）

- 新文件 `Controls/ConversationOverlayWindow.cs`：无边框透明置顶悬浮窗，
  点击穿透（WS_EX_TRANSPARENT|TOOLWINDOW|NOACTIVATE），与 EdgeGlow 同模式
- 位置：主屏幕中下部（Top = 屏高×66%，高 220px），文字水平居中
- 内容：两行——「我：指令」（26px 加粗）+「{唤醒名}：回复」（24px），
  白色不透明文字 + 柔和黑色投影（保证无背景下的可读性，投影不是背景）
- 显示规则（纯函数 `ConversationOverlayVisibility.ShouldShow`）：
  开关开启 && 主窗口不可见 && 状态 ∈ {Transcribing, Thinking, Executing, Speaking}
  && 已有指令文本；回到待命/开窗/静音时消失；250ms 淡入
- 配置 `ConversationOverlayEnabled: bool = true`，设置窗口加开关，保存即时生效
- 接线：MainWindow 订阅 TextRecognized / DSHReplied / StateChanged / IsVisibleChanged

### 唤醒修复（本地 SAPI 回归原始音频）

- `IAudioCapture` 新增 `RawDataAvailable` 事件；`AudioCaptureService` 每帧先发
  原始数据，再发增益后数据（云端识别/录音仍用增益后数据，受益）
- `LocalWakeWordService` 改订阅 `RawDataAvailable`（SAPI 自带 AGC，原始音频
  识别稳定）
- 默认增益 3.0 → 2.0（更温和）

## 测试

- `ConversationOverlayVisibilityTests`：13 个用例（忙碌状态/窗口可见/开关关闭）
- 现有全部测试 194 项通过

## 手动验证

1. 说"二狗"能唤醒（回归原始音频后）
2. 关闭主窗口 → 对话 → 屏幕中下部透明显示指令与回复，鼠标可穿透
3. 回到待命/打开窗口 → 浮层消失
