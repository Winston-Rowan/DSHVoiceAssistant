# 设计文档：自声过滤 + 可自定义快捷键 + 静默启动

日期：2026-08-23
状态：已确认，待实现
适用范围：DSHVoiceAssistant（WPF / .NET 8）

## 背景与问题

1. **自声误触**：TTS 播报回复时，扬声器声音被麦克风录回，VAD 触发后走「插嘴打断」
   分支，导致**二狗打断自己的播报**；播报结束回到倾听/待命后，回声残留还可能触发
   唤醒词或 VAD，产生空指令/误指令。
2. **快捷键不可自定义**：全局快捷键 Ctrl+Alt+D 键位写死（`MainWindow.OnSourceInitialized`），
   设置窗口只能开关不能改键位；且播报中（Speaking）按快捷键无效（`ForceActivate`
   仅允许 Idle 状态激活）。
3. **开机自启暴露界面**：开机自启注册的是裸 exe 路径，启动必然弹出主窗口；
   用户希望开机后静默驻留托盘。

## 决策记录

| 决策点 | 结论 |
|--------|------|
| 自声过滤与「插嘴打断」的关系 | 设置里加开关，**默认开启过滤**；开启时播报期间语音插嘴失效（只能快捷键打断），关闭时保留现有行为 |
| 过滤实现方式 | **软件门控**（不静音麦克风设备，无设备状态风险） |
| 快捷键 | 可自定义组合键，**保存后即时生效无需重启**；播报中按快捷键可打断接管 |
| 静默启动 | **仅开机自启时静默**：自启动注册带 `--silent` 参数；正常双击运行仍显示界面 |

## 功能 A：自声过滤（SelfVoiceFilter）

### 配置

`DSHConfig` 新增 `SelfVoiceFilter: bool = true`（appsettings 节点 `"SelfVoiceFilter"`）。

### 编排器（DSHOrchestrator）改动

1. **VAD 门控**：`OnLevelChanged` 中，当 `SelfVoiceFilter && _tts.IsSpeaking` 时
   **不调用 `_vad.Feed(level)`**（播报期间 VAD 完全收不到输入，`OnSpeechStarted` 不会触发，
   自声不可能走插嘴打断/开始录音路径）。
2. **播报结束复位**：`SpeakAndContinueAsync` 在 `_tts.SpeakAsync` 返回后调用
   `_vad?.Reset()`（清掉 VAD 内部"说话中"残留状态），再走现有 `ContinueListening`
   （保留现有 `_suppressVadUntil` 1.5s 抑制窗口）。
3. 开关关闭时：以上门控全部不生效，行为与现状完全一致（语音插嘴可用）。

### 唤醒服务缓存清理（防回声残留误唤醒）

`LocalWakeWordService` 与 `WakeWordService` 的 `IsEnabled` 由自动属性改为带 setter 的属性：
**false → true 时清空内部音频缓存窗口**（丢弃播报期间积累的回声片段）。

- LocalWakeWordService：setter 里 `lock (_gate) _chunks.Clear(); _chunkBytes = 0;`
- WakeWordService：setter 里 `lock (_gate) _chunks.Clear();`

编排器 `SetState` 中已有 `_wake.IsEnabled = state == DSHState.Idle`，播报结束回到
Idle/Recording 时会触发重新启用 → 自动清缓存。

### 行为矩阵

| 场景 | 过滤开（默认） | 过滤关 |
|------|----------------|--------|
| 播报中二狗自己的声音 | 完全忽略（VAD 不喂入） | 可能触发插嘴打断（现状） |
| 播报结束回声尾巴 | 忽略（VAD 复位 + 1.5s 抑制 + 唤醒缓存清空） | 1.5s 抑制窗口（现状） |
| 播报中用户语音插嘴 | 无效，需按快捷键打断 | 有效（现状） |

## 功能 B：可自定义快捷键

### 配置

`DSHConfig` 新增 `HotKeyCombo: string = "Ctrl+Alt+D"`（appsettings 节点 `"HotKeyCombo"`）。
`HotKeyEnabled` 保留。

### HotKeyService 扩展

新增静态解析方法（纯函数，可单元测试）：

```
TryParse(string combo, out uint modifiers, out uint vk, out string error)
```

- 支持修饰键：Ctrl / Alt / Shift / Win（顺序不限，`+` 连接）
- 支持主键：A-Z（大小写均可）、F1-F12、0-9、Space、Enter、Tab、方向键、Home/End/PageUp/PageDown、`-` `=` `[` `]` `\` `;` `'` `,` `.` `/` 等
- 规则：**至少一个修饰键**（Windows RegisterHotKey 要求）；非法输入返回明确错误信息
- 注册流程不变（Register 内部仍用 RegisterHotKey）

### MainWindow 改动

- 持有 `IDisposable? _hotkeyRegistration`，新增 `ApplyHotKey()`：
  解析 `_config.HotKeyCombo` → 释放旧注册 → 注册新组合 → 失败记日志
- `OnSourceInitialized`：`HotKeyEnabled` 时调用 `ApplyHotKey()`
- `OpenSettings()`（ShowDialog 返回后）：若 `HotKeyEnabled`/`HotKeyCombo` 变化则重新 `ApplyHotKey()`，**即时生效**

### ForceActivate 扩展（播报中快捷键打断）

`DSHOrchestrator.ForceActivate()`：

- 允许激活的状态：`Idle`、`WakeChecking`（现有）+ **`Speaking`**（新增：`_tts.Stop()` 打断播报，进入 Recording 倾听）
- `Recording`（已在倾听）/ `Transcribing` / `Thinking` / `Executing` / `Error`：忽略
- 托盘「开始倾听」与主窗口按钮共用该命令，同步生效

### 设置窗口（SettingsWindow）

新增「快捷键」区块：

1. CheckBox「启用全局快捷键（唤醒/倾听）」
2. 组合键捕获控件：显示当前组合（如 `Ctrl+Alt+D`），按钮「点击后按下新组合键…」→
   捕获下一次按键（KeyDown）：Esc 取消；必须含至少一个修饰键，否则提示并继续等待；
   捕获成功显示新组合，保存时写入 `HotKeyCombo`
3. 新增「自声过滤」CheckBox：「播报回复时忽略麦克风（防止自己的声音误触）」

## 功能 C：静默启动（仅开机自启）

### AutoStartHelper 改动

`Register()` 注册值改为 `"\"{exe}\" --silent"`。

新增 `EnsureSilentFlag()`：启动时调用——若 Run 键已存在但值不含 `--silent`，
重写为带 `--silent` 的版本（兼容已注册的老用户）。

### App.OnStartup 改动

```csharp
var silent = e.Args.Contains("--silent", StringComparer.OrdinalIgnoreCase);
var window = new MainWindow(...);
MainWindow = window;
if (!silent) window.Show();   // 静默启动不显示界面，仅驻留托盘
```

- 托盘双击/右键「显示主界面」→ `ShowMainWindow()`（现有实现，Show + Activate，对未显示过的窗口同样有效）
- `ShutdownMode = OnExplicitShutdown` 已保证不因窗口隐藏而退出
- 单实例保护不变；若已在运行，第二次启动仍提示（含静默参数场景同样提示，行为一致）

## 测试

### 单元测试（新增）

1. `HotKeyServiceTests`：TryParse 合法组合（Ctrl+Alt+D、Ctrl+Shift+F1、Win+Space…）、
   无修饰键、空串、未知修饰键、多主键 → 返回 false + 明确错误
2. 现有测试套件保持全绿

### 手动验证清单

1. 开启过滤：说长指令让二狗播长回复，确认不打断自己、无空指令触发
2. 播报中按自定义快捷键：立即打断播报并进入倾听
3. 设置里改键位（如 Ctrl+Alt+X）保存后：不重启即可用新键
4. 关闭过滤：语音插嘴恢复
5. 勾选开机自启 → 注册表 Run 值含 `--silent`；重启后无主窗口、托盘驻留；双击托盘图标可调出
6. 老安装升级：已有自启注册但无 `--silent` 时，启动后自动补上

## 不做的事（YAGNI）

- 不做硬件级回声消除（AEC）/ 麦克风静音
- 不做长按说话（对讲机模式）
- 不做静默启动的设置开关（固定"仅自启静默"）
