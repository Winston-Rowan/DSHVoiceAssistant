# 设计文档：语音结束对话

日期：2026-08-24
状态：已实现（229 项测试全绿）
适用范围：DSHVoiceAssistant（WPF / .NET 8）

## 需求

连续对话模式下，用户说"没事了 / 退下 / 滚吧"等词条即可**立即结束当前对话**、
回到待命（无需等待 30s 沉默超时），且不消耗 DSH API 额度。

## 方案

### 匹配器（`Utils/EndConversationMatcher.cs`，纯函数）

词表：没事了 / 没事儿了 / 没事啦 / 退下 / 退下吧 / 你退下吧 / 退下吧你 /
滚吧 / 滚开 / 滚蛋 / 不聊了 / 结束对话 / 结束吧 / 再见 / 拜拜 / 拜拜了 /
没你事了 / 没你的事了 / 没别的事了 / 没有别的事了 / 就这样吧 / 到此为止 /
就到这吧 / 不用了 / 不用了谢谢

匹配规则（防误触）：
- 文本归一化（去空白与标点）后**整句相等**，或**句子以词条开头**（词条长度≥2）
- **不做子串匹配**："打开记事本"、"滚动的天空怎么打开"、"我现在没事了"均不命中

### 编排器接入

`ProcessUtteranceAsync`：识别文本 → 剥离唤醒词 → **先查结束词条** →
命中则 `TextRecognized` 后直接 `SetState(Idle, "待命中")` 返回（静默，不播报），
未命中才进入 DSH 指令流程。结束指令在连续对话的任意一轮都生效。

## 测试

- `EndConversationMatcherTests`：35 个用例（词条命中含标点/空白变体、正常指令不命中、
  归一化规则）
- 全部 229 项通过

## 手动验证

1. 唤醒 → 连续对话中 → 说"退下" → 立即回到待命（托盘变绿，不再倾听）
2. 说"打开记事本" → 正常执行，不受影响
