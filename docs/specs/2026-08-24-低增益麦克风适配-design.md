# 设计文档：低增益麦克风适配（数字增益 + 自适应底噪）

日期：2026-08-24
状态：已确认，待验证
适用范围：DSHVoiceAssistant（WPF / .NET 8）

## 背景

用户麦克风增益较小，归一化 RMS 普遍低于 VAD 阈值（默认 0.02）与唤醒词 RMS 门控，
导致 VAD 永远不触发、本地唤醒被门控跳过。需要零配置的自动适配。

## 方案

| 层 | 改动 |
|----|------|
| 固定数字增益 `MicGain`（新配置，默认 3.0，范围 1~8） | `AudioUtils.ApplyGain` 对 16bit PCM 做整数增益（削波钳位 ±32767），在**采集源头**统一放大：VAD 电平、唤醒门控、SAPI 本地识别、云端 ASR 全部受益 |
| 自适应噪声底噪 `CurrentNoiseFloor` | `AudioCaptureService` EMA 跟踪：安静帧（rms < 底噪×4）缓慢更新（0.98/0.02），说话帧不参与；启动时重置 0.002 |
| VAD 自适应阈值 | `VoiceActivityDetector.Feed` 判定阈值 = `max(用户阈值, 底噪×4)`（经 `VADSettings.NoiseFloorProvider` 注入） |
| 本地唤醒 RMS 门控 | `avgRms < max(0.006, max(VadThreshold×0.5, 底噪×2))` 时跳过 |
| 设置界面 | 「语音检测」区新增「麦克风增益」滑块（1.0~8.0，0.5 步进），保存后重启生效 |

## 关键点

- 增益在源头做一次，下游零改动受益；信噪比不变，配合底噪下限不会放大噪音导致误触
- 底噪自适应：环境从安静变吵（空调/风扇）或从吵变安静都能收敛，VAD 阈值跟随
- `IAudioCapture` 接口新增 `CurrentNoiseFloor`（编排器 VAD 与本地唤醒服务使用）

## 测试

- `AudioUtilsGainTests`：增益=1 原样返回、静音保持、缩放正确、正负削波钳位、
  不改动输入、RMS 近似按比例放大
- 现有测试全绿；手动验证：低增益麦克风下唤醒词/指令可靠触发，环境噪音不误触发
