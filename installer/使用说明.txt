  DSH 语音助手 · 使用说明（2 分钟上手）
════════════════════════════════════════════

【它能做什么】
  对着麦克风说「老梁」（或「梁文峰」「梁总」），然后说出你想做的事，
  它听懂后会语音回复你，并真的去执行。例如：
    · 老梁，打开记事本
    · 老梁，搜索深圳天气
    · 老梁，下一首
    · 老梁，5分钟后提醒我喝水
    · 老梁，截个图
    · 没事了 / 退下  （结束对话）

【第 1 步：配置密钥（只需一次，约 2 分钟）】
  语音助手需要两个密钥，各管各的：
   1. 百炼密钥（必须）：用于语音识别和语音合成
      ① 打开浏览器访问 https://bailian.console.aliyun.com/
      ② 没有账号先免费注册；登录后点页面右上角「API-KEY」
      ③ 创建 API-KEY 并复制（形如 sk-xxxxxxxx）
   2. DSH 密钥（不用管）：DSH 运行环境自己用，在 DSH Desktop 里配置即可

【第 2 步：把密钥填进设置】
  启动应用后，如果弹出「欢迎使用」引导窗口，按引导操作即可；
  也可以手动打开设置：主界面右上角 ⚙ 齿轮按钮
    → 基础配置 → API 密钥 → 粘贴 → 保存

【第 3 步：开始使用】
  1. 确认状态是「待命中」（托盘图标绿色）
  2. 说「老梁」或按 Win+F2（可自定义）→ 状态变「倾听中」（黄色）
  3. 说出指令 → 它会执行并语音回复

【常用设置】
  · 唤醒词 / 快捷键：设置 → 唤醒与对话
  · 音色（默认 Andre 沉稳男声）：设置 → 语音播报
  · Siri 光效 / 对话浮层：设置 → 界面与反馈
  · 权限模式（完全访问/工作区受限/只读）：设置 → 基础配置

【常见问题】
  · 唤醒没反应？确认麦克风可用；低增益麦克风应用会自动适配
  · 下载安装包被 Windows 拦截？点「更多信息 → 仍要运行」即可
    （未签名安装包的正常提示，代码签名证书太贵了，作者以后会买）
  · 报错说 API 密钥无效？检查第 1 步粘贴的密钥是否完整、前后无空格

  遇到问题可查看应用目录下 logs 文件夹中的日志，或在项目仓库提问：
  https://github.com/Winston-Rowan/DSHVoiceAssistant
